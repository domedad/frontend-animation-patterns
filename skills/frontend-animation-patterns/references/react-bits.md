## Role and routing

React Bits provides expressive React text animations, interaction effects, animated components, and backgrounds. Use it for deliberate signature moments, portfolios, campaign pages, product showcases, and visually led landing pages. Keep dense product UI, forms, tables, and long reading surfaces quieter.

Use this file as an index. Open the exact official page before implementation to confirm its current dependencies, props, variants, and performance characteristics. The public groups below exclude the separate Pro catalog.

## Selection guidance

- Use Masked Heading, Gradient Text, Shiny Text, or Stroke Text for a readable hero emphasis; keep a static text fallback.
- Use Split Text, Blur Text, Fold Text, or Scroll Reveal for entrances; use Text Loop or Rotating Text for changing short phrases.
- Use Text Pressure, Variable Proximity, Text Cursor, or True Focus only when pointer/focus behavior has a touch and keyboard equivalent.
- Use Count Up for a highlighted metric and avoid animating every value in a dense table.
- Use Animated Content or Fade Content for quiet reveal; Pixel Transition, Halftone Reveal, or Scroll Expand for a single stronger media transition.
- Use Click Spark for brief user-triggered delight. Restrict cursor trails, crosshairs, magnets, and distortion effects to fine-pointer showcase surfaces.
- Use card, gallery, carousel, menu, navigation, and slider components as presentation patterns. Do not replace accessible product primitives when the React Bits component is primarily decorative.
- Use one background as a decorative layer behind readable content. Prefer quiet fields such as Aurora, Silk, Threads, Dot Grid, or Gradient Waves before high-energy Hyperspeed, Lightning, Ballpit, or Liquid Chrome.
- Never combine a signature text animation, cursor effect, animated component, and high-energy background in the same viewport without a clear art direction.

## Stack, resilience, and access

- The catalog is React-oriented and publishes JavaScript/TypeScript plus CSS/Tailwind variants. Match the existing project stack.
- Dependencies differ per entry and may include GSAP, Motion, Three.js, OGL, or other rendering libraries. Read the exact page before installing anything.
- Preserve semantic HTML, accessible names, keyboard behavior, and static content. Canvas/WebGL effects must remain decorative.
- Follow the Skill's Default Motion Policy rather than system motion settings. Only remove parallax, trails, distortion, loops, and scroll-linked movement when app motion is explicitly off; keep content visible.
- Budget GPU-heavy backgrounds and cursor effects carefully, pause them offscreen, and test low-power/mobile devices.
- The repository is distributed under MIT plus the Commons Clause. Review the current terms before redistribution, especially when packaging components as a paid product or service.
