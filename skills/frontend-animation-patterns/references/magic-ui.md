# Magic UI Motion Catalog

Official source: [Magic UI components](https://magicui.design/docs/components) · [installation](https://magicui.design/docs/installation)

Last reviewed: 2026-08-13.

Magic UI uses the shadcn/ui installation pattern for React applications. A current component is normally added with `shadcn@latest add @magicui/<slug>` and imported from the project's UI component directory. Verify the component page, dependencies, and project compatibility before running any install command.

## Core Motion Components

- [Blur Fade](https://magicui.design/docs/components/blur-fade) — reusable reveal with direction, offset, blur, delay, duration, and in-view options.

- [Marquee](https://magicui.design/docs/components/marquee) — continuous logo, quote, or card strip; keep essential content available without motion.

## Usage Constraints

- Treat Magic UI as React-oriented copy-in component code, not a framework-neutral runtime.
- Confirm the official component page still exists and review its current props before implementation.
- Keep only the effect needed for the brief; do not install a catalog of unused components.
- Preserve static readable content for server-rendered/loading states and when app motion is explicitly off; do not follow system motion settings automatically.
- Avoid continuous backgrounds, custom cursors, or scroll velocity on dashboards, forms, data tables, and accessibility-critical flows unless explicitly justified.
